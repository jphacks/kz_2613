# 実機検証ゲート

[現行仕様・確認範囲](../../verification.md) ／ [開発資料](../README.md)

各ゲートには、PCのOS、Minecraftの正確な版、スマホのOSとブラウザ、ネットワーク構成、操作者、実施日、観測結果、合否を記録する。単体テストでは代替できない。

2026-10-24に、通信試作品（Node.js参照実装）で一部のゲートを実施した（[判断記録](../decisions/2026-10-24-prototype-validated.md)、`docs/develop/handoff/BUILD_LOG.md`）。**Minecraftでのゲート（G1）は未実施。**

Node.js試作品は疑似ゲーム画面とスマホ実機で確認済み。Rust版はPC上のシミュレーションのみ実施済み。Minecraft、Tauri、Rust版の実入力・スマホ3台による実機試験は未検証。今回の文書整理で新たな実機試験は実施していない。 [E]は観測事実の区分で、ユーザーの今後の明示判断より優先しない。

## 推奨する実施順

1. **G1-A/B/C**：Minecraftで、試作品の `on` モードを使って試す。キー割当と、Raw Input・感度の設定を記録する。
2. **G4-C**：Rust版をシミュレーションと実機3台で、参照実装と比べる。
3. **G2-A**：上流回線を外したホットスポットで試す。
4. **G1-D**：前面ウィンドウの確認を実装したあとに試す。
5. **G4-A/B**：Tauriと配布。
6. **G5**：デモを繰り返す。
