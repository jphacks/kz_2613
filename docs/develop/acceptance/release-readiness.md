# 一般向けリリースの判定チェックリスト（#168）

- 作成日：2026-11-15（Claude Code。Issue と BUILD_LOG の記録から整理）
- 位置付け：**この文書は一般公開の承認ではない**。不特定多数へ配布してよいかを、チームが Go/No-Go で決めるための材料。この文書の整備が終わっても、リリースは完了しない。
- 方針（Q41、kume 本人の確定。チーム全体の合意・担当・公開日・配布先は未決定）：Award Day（2026-11-15）はデモ・会場での試遊が中心。一般公開は、P0 の入力・停止の安全試験と、開発環境のない Windows 11 x64 での配布・スマホ参加・実ゲームの受入に合格した後に、既知の制限・利用条件・公開場所・責任者を明示し、チームの Go 判断を得て行う。インストーラー・zip を作ること自体は続けてよい（ビルドできたことは公開の承認ではない）。

判定の欄は「合格」「不合格」「未実施」「一部」。**自動試験の合格を実機の合格と読み替えない**。

## 3. 現時点の判定案

**No-Go（一般公開は延期）**。必須のゲートのうち、安全停止（#39・#285）、反復デモ（#217）、クリーン PC での導入（#219・#41）、ランタイム（#148）、会場の Wi-Fi 後始末（#415 の B）が未合格のため。Q41 の方針どおり、Award Day は管理された会場でのデモ・試遊に専念する。

- 会場の試遊は、スタッフが PC の前にいて緊急停止（Ctrl+Alt+F12）を押せる状態で行う。
- 試遊のための内部配布が必要な場合は、配布先・端末・手順・リスクをチームで限定する。
- 判定案は Claude Code が記録から作ったもので、**最終判断はチーム**。
