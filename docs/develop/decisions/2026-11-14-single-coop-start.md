# 分担操作を1つのボタンで開始する

2026-11-14の利用者判断（#440）で、開始操作を「分担操作開始」に統合する。ホストはロビーのリモコンでゲームのメニューやワールドを準備する（#405）。

通常の製品画面では、ホスト（P1）がロビーで `READY` を送る。ホストの接続、確定済みの分担と参加者、担当の確認、入力ドライバー、緊急停止キー、対象ゲームの前面をサーバーで確認する。前面が変わってepochが更新された場合は再操作を求める。条件がそろえば全出力を解放し、epochを更新して `coop` に進む。

通信契約を版5とする。従来の `PREPARE` と `preparing` を使う経路も引き続き受け付ける。この経路での「準備をやめて分担に戻る」（#427）も利用できる。

ロビーのリモコンだけでMinecraftの起動後にワールドへ入り、分担操作を開始できるかは、実機で確認する。

## 追記（2026-11-15、#556）

ロビーで選んだゲームが起動していれば、前面でなくても「分担操作開始」を押せる。押した瞬間（`READY` を受けたとき）だけ対象ゲームを前面へ出し（`focus_for_coop`、#138 と同じ）、入力先が一致してから全解放・epoch 更新をして `coop` に進む。前面にできなければ開始せず、入力も送らず、理由と手動で前面にする案内を返す。ゲームが起動していない（ウィンドウがない）ときは、従来どおり前面にするまで開始できない。参加者の接続・分担の決定などでは前面を奪わない。

展示の連続試遊（#546）で、協力プレイの終了後に PC アプリが前面になったまま次の組が開始できなくなるのを防ぐため。
