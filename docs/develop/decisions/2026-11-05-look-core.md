# 視点の累積差分・補間を純計算へ分離する（#172）

## 境界と維持する処理

`look.rs` の `Look` は、認可済みの差分と明示時刻を受け、未処理量、到着間隔、平滑化、端数と出力量を計算する。セッション、接続、OS入力、タイマー実行器を参照しない。Hubには担当認可、epoch/lseq/cx/cyの照合、累積差分への変換、4msタイマー予約、実際のマウス送出、ログ/通知の境界を残す。

- 4ms周期、直近2秒の最大到着gap×0.5を設定の最小/最大時定数へclampする規則を維持。既定30〜120msも変更しない。
- gapは1000ms未満だけ履歴に入れ、ちょうど2秒経過した履歴は保持、2秒超で破棄する。
- 補間係数は `1 - exp(-dt/tau)`、未処理量が両軸とも0.5px未満のときだけ残りを全量消費する。整数化はtrunc、端数は次回へ保持する。
- 停止時は未処理量と端数を捨てる。既存の到着履歴、時定数、送出済み診断集計の保持/100ms報告は変更しない。
- coreは `Movement` を返し、Hubが入力アダプターへ送出した後に `record_output` を呼ぶ。送出失敗でも診断集計を進める#170の現行挙動も保持する。

極端に大きい量では、従来からOS要求はi32、診断集計はi64へそれぞれ変換される。`Movement` は両方を保持して、この型幅の違いを無断で合わせない。入力値の新しい検証や制限はこの責務分離へ混ぜない。

## 回帰試験

既存のHub/通信の累積値・欠番・重複・順序乱れ・旧epoch拒否は保持した。純計算の8試験で、4msと指数係数、符号付き移動と端数保存、0.5px境界、最大gap/最小最大時定数、1000ms/2秒の境界、停止破棄と診断保持、入力禁止tick、急な大量移動の整数化を固定する。時刻は引数で直接渡し、sleepも実マウス移動も使わない。

コマンドと結果は[BUILD_LOG.md](../handoff/BUILD_LOG.md)を参照。実機の操作感やWindowsの受取りを自動試験の成功へ読み替えない。
