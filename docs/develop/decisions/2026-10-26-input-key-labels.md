# 操作表示を実際に送る入力名へそろえる（#150）

ユーザーの「操作キーの上に書いてある文字がMinecraftに引っ張られすぎ」という指摘を受け、「送るキー名を中心にする（左クリック・Eキーなど）」を採用する（2026-10-26）。

- すべてのゲームで、スマホのボタンはホストの `game.keys.actions` が示す実際の入力名を主表示にする。例えば操作IDが`inventory`でも、設定をRへ変更した場合は「Rキー」と表示する。未割り当て・送信できないキーは「送らない」とする。
- 操作定義の「攻撃」「持ち物」等の名称は主表示へ流用しない。グループの見出しとPC・スマホの分担確認も「キー」「クリック」「ホイール」「マウス移動」の入力種類と実キーで示す。
- ホストのリモコンも入力名で表示する。Minecraftのインベントリに対応するボタンは、既存の送信処理と同じく設定を反映した実キーを示す。他ゲームでは従来のEキーを示す。
- 操作ID・定義の内容・分担・送信メッセージ・認可・安全停止の処理は従来どおりとし、表示からゲーム内の動作や未検証ゲームの互換性を断定しない。

未検証の定義は引き続き未検証と表示する。自動試験で確認する表示と送信IDの対応は、実ゲームとスマホの実機受入とは区別する。
