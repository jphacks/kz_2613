# Minecraftの名称・画面・デモ素材の利用条件（#42）

- 確認日：2026-10-25（Claude Code）
- 根拠：Minecraft Usage Guidelines（公式）<https://www.minecraft.net/en-us/usage-guidelines>
- 参考：Minecraft EULA <https://www.minecraft.net/en-us/eula>（本文は未精読。動画・スクリーンショットの扱いは上のガイドラインで確認した）
- 状態：**[E]** は公式ページを読んだ記録（実機検証を意味しない）、**[P]** は本プロジェクトへの当てはめ（提案）。利用許諾の取得・適合性の確定を意味しない。大会運営の判断だけで権利者の利用条件を変更できるものではない。

## 1. ガイドラインの要点 [E]

1. **名称・ブランド・素材の定義：** 名称（ゲーム名・紛らわしい名前を含む）、ブランド（ロゴ・フォント・テクスチャなど）、素材（コード・画像・音声、**ゲームから撮った動画・スクリーンショット**）が対象。
2. **共通の禁止事項：** 公式・承認済み・提携と誤解させない。ゲームやゲームファイルを再配布しない。ガイドラインが認めていない商用利用をしない。
3. **免責表示：** 「NOT AN OFFICIAL MINECRAFT [PRODUCT/SERVICE/EVENT/etc.]. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT」に類する表示を、製品・説明・Webページなど**関連する資料すべてに目立つように**入れる。責任者・連絡先も明示する（チャット・フォーラムのリンクは不可）。
4. **名称の使い方：** Minecraftの名前は**副題・説明**でだけ使える。主要な名前・目立つ部分にしない。ロゴやブランドの要素を自分のロゴに使わない。
5. **「共有」は商用利用の扱い：** 無償でも、作ったものを他の人と共有すれば「commercial use」の扱いになり、商用利用の項目に従う。
6. **動画・配信・スクリーンショット：** 自分が遊んでいる動画・配信・スクリーンショットは作成・共有できる。収益化する場合は、無料で視聴でき、独自の内容（解説など）を十分に加えること。Minecraftと無関係な製品・サービスの宣伝に使わない。動画を販売しない。
7. **Minecraftの素材の流用：** Minecraftのソフトウェア・音楽・音声を製品の一部にしない（商品の項目）。

## 2. Re:Cooplayへの当てはめ [P]

| 対象 | 判断 | 対応 |
|---|---|---|
| 製品名 | 「Re:Cooplay」を主名称、Minecraftを対応ゲームの説明とする方針 | 製品名・アイコンにMinecraftの名前・ロゴ・テクスチャを入れない |
| アイコン（`apps/desktop/icons/`） | 3色の円で、Minecraftの素材は見当たらない | 変更なし |
| PCアプリの「Minecraft Java Edition」表記 | 対応ゲームを説明する表記として扱う | ②ゲーム選択の画面に英文・和文の免責表示を加えた（`apps/web-static/app.html`） |
| 免責表示 | 必須 | PCアプリ・README・発表資料・デモ動画の説明に「Minecraftの公式製品ではありません。Mojang・Microsoftの承認・提携はありません」と英文（上記）を入れる |
| 責任者・連絡先 | 必須。掲載先は未確定 | チームが公開を認めた責任者名と直接連絡できる連絡先を決め、README・発表資料等へ反映する。GitHub Issueだけで条件を満たしたとは判断しない（公式はチャット・フォーラムのリンクを不可としている） |
| 発表でのゲーム画面・デモ動画 | 個別確認が必要。汎用の協力操作製品を「Minecraftと無関係ではない」と断定しない | Minecraftに無関係な製品の宣伝に当たるか、スポンサー表示・会場投影等の条件を実際の素材・開催形態で確認する。不明なら権利者に確認し、確認できるまでは疑似ゲーム画面を使う |
| 配布パッケージ（#41） | Minecraftのファイルを含めない方針 | パッケージにゲームのファイル・素材を同梱しない。配布物ごとに内容を確認する |
| ワールド・スキン | ワールド名・他人のスキン・サーバー名が映ると第三者の権利・個人情報の問題がある | デモ用の新規ワールドと既定スキンで撮影する |
