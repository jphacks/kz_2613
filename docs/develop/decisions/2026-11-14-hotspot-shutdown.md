# PCアプリ終了時のホットスポット停止

[#415](https://github.com/jphacks/kz_2613/issues/415) のAを実装する。WindowsがOFFと報告した状態からホストの起動要求が成功した場合に、同じ管理オブジェクトをそのプロセスの終了まで保持する。起動要求と停止は直列化し、WindowsがすでにONと報告した場合は現在の所有状態を維持する。起動後にPCの上流回線が変わっても、終了時に別の接続プロファイルから管理オブジェクトを作り直さない。

PCアプリ終了時は新規の起動要求を止め、入力の解放とスマホへの終了通知を済ませてから停止を試みる。ホスト側は停止結果を最大2秒待つ。停止失敗や時間切れは `hotspotShutdown` として既存のセッションログに記録する。ログには固定の結果コードだけを残す。

所有情報はプロセス内に限る。強制終了時や、Windowsの設定から手動でOFF・ONし直した場合の運用は実機検証に残す。非管理者のWindows配布版で、手動でONにした場合とアプリがONにした場合を別々に試す。SSID・パスワードの変更と復元は #415 のBで扱う。
