# 協力プレイの開始時だけ対象ゲームを前面にする（#138）

ユーザーの「前面にこっちからやらなくても勝手になってほしい」という判断を実装する。Ready・明示再開・条件を満たした切断後の自動復帰で、対象ゲームが前面でなければ前面化を要求する。一時停止中の通常のPCアプリ操作や、参加者・担当確認・入力ONなどの条件が不足する間は要求しない。

開始要求の可否と入力の許可を分ける。前面が不足していても開始ボタンは押せるが、ホストは停止した状態で前面化し、対象ウィンドウの実際の照合結果が成功した場合だけcoopへ進む。入力先の照合や認可は省略しない。前面化でepochが変わった場合も旧入力は破棄し、開始前の押下を復元しない。

Windowsが拒否した場合は準備・一時停止のまま手動切替を案内する。自動復帰の前面化が失敗した場合は期限を解除し、繰り返し前面を奪う要求を送らず、ホストの明示再開を待つ。ホストの明示PAUSEやPCアプリへの手動復帰が自動復帰を解除する既存の条件は維持する。

dry-runの模擬前面・模擬前面化ではOSのウィンドウを変更しない。これはWindowsでの前面化成功、Minecraft等の互換性、実際のスマホ操作を検証した証拠ではない。
