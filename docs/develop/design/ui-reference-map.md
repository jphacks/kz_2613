## 仕様に合わせた変更

- 元画像の2人・4人の仮配置は固定3人にする。接続済みを個人Readyと呼ばず、ホストだけがゲーム準備後にReadyを送る。
- 灰色キャラクター枠の代わりにCSSの星と役割の記号を表示する。これは差し替え可能な仮ロール表現であり、完成キャラクター素材とは呼ばない。
- PCの白い側面、星柄の黄〜桃背景、シアンの丸枠と点線、太い紫文字を共通化する。PC・スマホ双方で実際の文字・ボタン・入力域を実装する。
- スマホの操作配置編集案は、移動・視点・アクションの固定分担へ読み替える。横画面の編集や仮の保存ボタンを置かない。
- 文字の読みやすさ・縦画面の可変サイズ・操作領域を優先し、元画像の絶対座標や一部の低コントラスト文字はそのまま使わない。素材に実物ロゴがないためRe:Cooplayは文字ロゴで表現する。

## 素材の配布

背景画像5枚だけを同梱し、画面案全体は同梱しない。既存Windows配布スクリプトの再帰コピーでstyles/scripts/assetsも含める。Minecraft公式の画像・キャラクター・フォントを追加していない。
