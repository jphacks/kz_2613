# 生成操作画面の確認

- `rust-p1-*`はRust実バックエンドのDRY_RUN＋FAKE_TARGETと試験用定義を使い、P1のブラウザー＋模擬P2/P3で撮影。準備→明示Ready→生成画面、アクションの押下・解放（送信2・未ACK0）、Pause→リモコン、視点パッドの元画面への復帰（重複0）を確認した。
- `preview-p2-*`・`preview-p3-*`・`pc-*`は表示専用の模擬状態。通信認可はRustの44件の通信試験で別に確認した。表示試験を実機試験と混同しない。
- P1〜P3×縦6サイズの18条件で横はみ出し0、44px未満の操作ボタン0。小画面では操作欄だけスクロールし、P1の停止ボタンは画面内に残る。
- PCは1280×720・1920×1080。担当・実キーを分担カードと確認ダイアログへ表示。初期描画の重複処理に起因する例外を検出して修正し、新規タブ41/42で再検証した。最終正常画面のコンソール警告・エラー0。
- Minecraft実入力・Tauri実窓・スマホ実タッチは未検証。実セッションは3人固定。1〜4人の分担案の計算は、2人プレイや4人目の参加の実装完了を意味しない。
