# 試作品の名残を整理する（必要人数・旧START・構造チェック）

2026-10-25のユーザー指示「試作品の名残でほかにもいらなそうな機能は修正のIssueを出していって」「やっていって」に基づく整理（Issue #115・#116・#117）。入力のON（#114）、Node参照実装の削除（#86）と合わせて行った。

- **必要人数（#115）：** 人数はReadyの時点の接続人数で自動に決める（[参加人数の決定](2026-10-25-variable-players.md)）ため、`config.json` の `requiredPlayers`（読むだけで使っていなかった）と `required` メッセージを廃止した。診断画面の「必要人数1/2/3」と、押しても効かなかった進行の「協力プレイ」ボタンを外し、「参加人数：2〜4人（Readyの時点の接続人数）」と表示する。`game.required` は最低人数（2）として残す。既存の設定ファイルに `requiredPlayers` が残っていても無視して起動する。
- **旧開始手順（#116）：** `command: START`（`PREPARE` の別名）と `game.canStart`（`canReady` と同じ値）を削除した。スマホ・PC画面はどちらも使っていなかったため、通信契約の版（v4）は上げない。PC画面から使われなくなった `startView`・`phaseView` とその試験を削除し、操作設定の手順の文言を今の開始手順に合わせた。
- **構造チェック（#117）：** 残す。Rustを使わずに速く失敗を知らせる役割があるため。雛形をコピーした直後の確認という説明を改め、必須ファイルに操作定義・主要500タイトルの一覧・操作定義の文書を加えた。`docs/handoff/ISSUE_PLAN.md` は開発の手順書から参照されている現役の文書なので、必須のまま残す（#117 本文の「古い計画文書」は誤りだった）。
