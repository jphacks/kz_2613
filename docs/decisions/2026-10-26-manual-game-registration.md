# Steam・Epicで見つからないゲームを手動で登録する

Issue #49（起動先の手動登録）と #56（任意のPCアプリの登録の一般化）をまとめて実装した。

- **登録のしかた：** PC画面のゲーム一覧の「＋ 追加」を押すと、ホストがWindowsのファイル選択の画面を出し、PCの前の人がゲームの実行ファイル（`.exe`）を選ぶ。登録先の場所を画面やスマホから受け取る経路は作らない。
- **受け付けるもの：** 存在する絶対パスの `.exe` だけ。`.bat`・`.cmd`・ショートカットなどは受け付けない。起動は実行ファイルを**引数なし**で行い、作業フォルダーは実行ファイルのフォルダーにする。引数やコマンドを登録する手段は用意しない（危険な起動引数を受け付けないため）。
- **権限：** 登録・名前の変更・解除は、PC本体から接続した画面（`monitor`）だけが行える。スマホ（`player`）から送っても無視する。
- **表示：** 一覧には「手動登録」「未検証」の印を付け、Steam・Epicの件数とは分けて数える。操作定義は汎用の定義（WASD・マウス）を使い、操作が届くかは未確認と案内する。入力の送り先は実行ファイルのフォルダー内のプロセス（Steam・Epicのインストール先と同じ扱い）。
- **保存先：** `%LOCALAPPDATA%\Re-Cooplay\manual-games.json`（ユーザーのフォルダー。リポジトリには置かない）。ログには登録したIDと操作の種類だけを残し、ゲームの名前・場所は残さない。
