# Web側の実装ルール

> **2026-10-24：** MVP画面の基準はNode.js試作品で実機動作を確認した静的HTML/CSS/JavaScript。Reactは任意で、現在のこのディレクトリにはReactひな形が残る。試作品とRust版の取り込みは後続作業。通信契約は `docs/architecture/protocol.md` を参照する。

- ルートの `AGENTS.md` と最新の製品判断を継承する。スマホ画面とPC画面は静的HTMLを基準に共通の通信契約を守る。Reactを採用する場合も任意の再実装として扱い、ネイティブモバイルアプリを別途必須にしない。
- P0は要件定義v0.3の割当に従う。P1は8方向移動・ジャンプ・スニーク・ダッシュ、P2はドラッグ視点、P3は攻撃・使用・ホイール・E・Q。旧ひな形の十字キー・方向視点を必須仕様としない。
- `pointerdown/up/cancel`、`touch-action: none`、ページの表示状態とライフサイクル、複数指操作に対応し、安全に入力を解放する。
- クライアントが申告する役割・ホスト権・モードを信用しない。サーバーの状態を正とする。
- 未接続を明確に表示する。現在の画面は**操作機能のないひな形**。
