## 残した情報・分離した情報

- 本番に残す：担当、操作、参加状況、準備・Ready・Pause・再開、実際の操作先、入力OFF・対象外・未検証定義の警告、緊急停止と設定への入口。
- 診断に分離：RTT、平均・最大、送信件数、未ACK、通信経路、通信テスト。スマホ右上の「…」から開く。開く直前に押下を解放し、開いている間は新しい入力・視点・リモコン移動を送らない。
- PCの段階ナビは操作設定の中へ移動。重複する停止・再開説明を削除。検証状態・安全上必要な警告は隠さない。

## 必要な差異と未確認事項

- 原案の4人表示を、現在の3人の実セッションへ置換した。4台目の接続や2・4人での実プレイを追加したようには見せない。赤い画像は提供素材として保存するが、架空の参加者は表示しない。
- 原案の各人Ready・担当選択表現を、既決仕様の「固定分担＋ホストだけの明示Ready」に置換した。接続したP2/P3を独立に準備完了したようには表示しない。
- ゲーム選択の空枠には選択可能なMinecraftを表示する。未実装の任意パス入力欄を置かない。検出ゲーム一覧との接続は #94 の別作業。
- 原案の「使う E」はMinecraftの実操作と異なるため「持ち物」に変更。見本帯の3キーも固定文字ではなくホストが送った実キー設定を参照し、長いキー名は文字を小さくする。完全なキー名は操作設定でも確認できる。
- スマホの「操作配置へ進む」は、配置編集を実装したと誤認させない「操作画面へ進む」に変更。待機中は無効で、ホストのReadyで担当操作へ自動遷移する。
- キャラクター色は担当に追従するため、P2の比較画像は緑。原案2枚の青と異なるが、画像形状・カード位置・共通配色を維持した。
- 正式なフォント名・編集可能な原本は未提供。既存のローカルフォント構成の範囲で太さ・文字サイズ・縁取りを調整した。完全な字形一致は未確認。
- ブラウザー表示は模擬データ。接続前の画像は通信スクリプトを省いた製品の初期DOM。新UIのAndroid/iPhone実タッチ、実機ノッチ、Minecraft・Tauriでの再確認は未実施。
- 追加のRust＋ブラウザー統合環境の新規起動は、自動承認レビューの利用上限で実行されなかった。既存Rust実行ファイルでの通信・停止試験と表示専用の遷移確認は区別する。

### マージ前レビューでの診断処理の修正

診断開始時は既存の`release_inputs`でサーバーの保持・保留入力と視点を破棄する。診断中も非注入の通信テストだけは押下・解放を200件送信できるようにし、通常の操作・視点は引き続き抑止する。controller本体とphone-viewを実行する回帰試験をCIへ追加し、通信契約の停止試験には保留連打の破棄を追加した。

この修正はDOM・CSS・画像を変更しない。104画面と`source-fingerprints.json`は修正前コミット`3719777`で撮影した証拠として保持し、修正後に実ブラウザーやスマホで再撮影したとは扱わない。

## React移行の検証価値

今回の見た目の再現には不要と判断した。主な難しさは素材の採寸、3人・ホストReadyとの整合、短い縦画面の操作領域であり、React化だけでは解消しない。今後、状態ごとのDOM更新・共通カード・生成操作がさらに増える場合は、入力送信とPointer Captureを維持する小さな比較検証には価値がある。今回のPRへ移行は混ぜない。
