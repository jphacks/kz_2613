# 作品名の見出し（案）

ふつうの見出しに見えて、少したつとキャラクターが文字を動かす案です。各案の下の文は、本文との並びを見るためのものです。
動きはおよそ10秒で1周し、最初の約3秒は止まっています。

生成：`python scripts/readme/title.py`
