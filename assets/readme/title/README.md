# 作品名の見出し（案）

ふつうの見出しに見えて、少したつとキャラクターが文字で遊ぶ案です。作品名はGitHubの見出しと同じ32px、キャッチコピーは一回り小さい24pxです。各案の下の文は、本文との並びを見るためのものです。

動きは10〜12秒で1周し、最初の約3秒は止まっています。

生成：`python scripts/readme/title.py`
